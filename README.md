# happy-wakey.github.io

The public Astro marketing site for **Happy Wakey**.

A local-first native morning dashboard for calendar, weather, markets, news, pages, and reminders.

## Development

Use Node.js 22.22.1 or newer.

```sh
npm ci
npm run dev
npm run build
```

Astro writes the production site to `dist/`. The committed GitHub Actions workflow builds pull requests and deploys the default branch to GitHub Pages.
